This FFplus experiment focuses on scaling the core innovation of SLICK+ through HPC-enhanced generative AI. Specifically, the experiment will validate how EuroHPC infrastructure can dramatically increase the performance, cost-efficiency, and scalability of the following components:

- Multilingual speech-to-text transcription across large datasets of employee-generated videos
- Sentiment detection and language model tuning across domain-specific content
- Real-time delivery of hyper-personalized learning modules using AI-driven inference pipelines
